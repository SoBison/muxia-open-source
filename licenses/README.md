# Component notices

Original copyright and license texts are preserved by component/archive and version. Archive-named directories end in `.sources` only to keep archive-ignore patterns from hiding license texts; framework-named notice folders end in `.notices` for the same reason; file contents are unchanged. The complete Release asset retains original archive hashes and source bindings.

A source archive may contain multiple GPL/LGPL alternatives; their presence is not a claim that every alternative was enabled in a linked binary. Actual component configuration and the included notices determine the applicable terms. No single repository license overrides component terms. See the root APPLICATION-OBJECTS-PERMISSION.txt for the existing permission regarding the separately supplied App objects.
